# EXXY intro — web app

Vite + React + GSAP. The intro is a pre-rendered video (Blender Cycles) with
the EXXY name, tagline and button as real HTML on top.

```bash
npm install
npm run dev            # local dev server (?realtime shows the old real-time 3D scene, ?realtime&orbit to look around)
npm run build          # normal production build -> dist/
npm run build:single   # one self-contained file for the private preview -> dist-single/artifact.html
```

- `src/Intro.jsx` + `src/intro.css`: the intro page. The video ends on the logo wall
  bloomed to pure white; the page is the same white with `public/exxy-logo.svg` in the
  exact same place, so the handover is invisible. `--mark-h` in `intro.css` must match
  the logo size set in `blender/terrace.py` (LOGO_H, GLIDE_STOP).
- `public/intro/`: `portrait|landscape.mp4` plus `-start.jpg` (poster shown while the
  video loads). Made with `blender/terrace.py --gpu --animate 3.25` then
  `blender/encode.py <frames> public/intro/<shape>.mp4 --stills public/intro/<shape>`
  (delete the `-end.jpg` it also writes; the page doesn't use it).
- `public/exxy-logo.svg`: generated by `python blender/logo.py web/public/exxy-logo.svg`.
- Deployed demo: Vercel project `exxy-demo` (`npx vercel deploy --prod` from `web/`).

Old real-time scene (kept for comparison, `?realtime`):

- `src/scene/RealtimeTerrace.jsx`: the canvas, camera and lights.
- `src/scene/layout.js`: every position, size, colour and the sun direction in one place.
- `src/scene/Terrace.jsx`: the architecture (floor, walls, pergola, sky, sea).
- `src/scene/Furniture.jsx`: places and recolours the EXXY models.
- `src/models/*.glb`: generated by `blender/build.py` (don't edit by hand).
